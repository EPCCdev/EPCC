# The parts of EPCC

* [`epcc-core`](epcc-core): the converter itself, used by both programs: reading and writing
  every format, thinning, and running conversions.
* [`epcc-gui`](epcc-gui): the window program, `EPCC` in the download.
* [`epcc-cli`](epcc-cli): the command line program, `epcc` in the download's `command-line`
  folder.

[docs/BUILDING.md](../docs/BUILDING.md) explains how to build them and how the code fits
together.
